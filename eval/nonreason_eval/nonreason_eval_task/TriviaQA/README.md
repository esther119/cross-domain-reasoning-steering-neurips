# nonreason_eval_task/TriviaQA — the TriviaQA closed-book eval pool (the NON-REASONING domain)

| file | what |
|---|---|
| `test.jsonl` | 11,313 rows = the full `mandarjoshi/trivia_qa` `unfiltered.nocontext` **validation** split in native order (the `test` split ships without answers). Fields per row: `problem`, `question_id`, `level` (`"trivia"`), `gt` (canonical answer), `aliases` (canonical value + the dataset's alias list, deduplicated after normalization). The eval harness (`eval/nonreason_eval/pipeline/eval_nonreason_{steering,vllm}.py --dataset TriviaQA`) reads this file and subsamples it with `--random_sample --sample_seed 42 --max_examples 500`; results land in `rand42_500/`, the same convention as MATH500. |
| `eval_rand42_500.json` | documents that selection: the 500 pool indices + `question_id`s the rule picks (shuffle `range(11313)` with `random.Random(42)`, keep the first 500, restore file order). Verification only — the harness recomputes the selection, it does not read this file. Zero overlap with the extraction pool. |

The extraction pool (`train.jsonl`: the first 10,000 rows of the seed-42 shuffle of the 87,542-row deduplicated train split, disjoint from validation by `question_id` and normalized question text) lives in `extraction/nonreason_extraction/nonreason_pool/TriviaQA/`; both files are materialized, byte-identically, by `extraction/nonreason_extraction/nonreason_pool/prepare_triviaqa.py` (the branch's `scripts/prepare_triviaqa.py`). Config: `unfiltered.nocontext` (one row per question; `rc.nocontext` repeats each question per evidence document and the context-bearing configs must not be used closed-book).

Grader: `eval/nonreason_eval/pipeline/triviaqa_utils.py` — the answer is what follows `</think>` (last `Answer: X`; a generation that never closes `</think>` is unfinished = wrong), normalized exact match against `gt` + `aliases` (`--em_mode aliases`, the official TriviaQA metric; `contains` / `value` are diagnostics reported alongside in `metrics.json`). Imported 2026-08-23 from branch `triviaqa-non-reason` (`data/TriviaQA/`), byte-identical.
