# APPS train pool

`train_code.jsonl` — APPS train split in file order (parquet branch of `codeparrot/apps`; the legacy script loader no longer works).
Loaded by `extraction/src/apps/data.py`; traces are generated by `extraction/src/apps/gen_apps_vllm.py` and graded by
`extraction/src/apps/scoring.py` (same pass/fail semantics as the APPS eval). The shipped 1.5B traces and the resulting
vector live in `../../code_extraction_1.5B/result/`.
