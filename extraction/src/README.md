# extraction/src — shared extraction code

Used by every `*_extraction_<size>/pipeline/` script (run from the repo root):

| file | role |
|---|---|
| `hidden_analysis.py` | the one extractor: forward pass, tag each `\n\n` step inside `<think>` as check / switch / other with `--keywords math|code|logic|nonreason`, save layer activations to `hidden_<type>_0_N/hidden.pt` (+ `prompts.json`) |
| `keyword_sets.py` | loads `KEYWORD_SETS` from `extraction/*_extraction/*_keyword/keywords.json` (folder name = `--keywords` name) |
| `vector_generation.py` | `S = mean(check ∪ switch) − mean(other)` per layer → `vector_<prefix>/layer_L_transition_reflection_steervec.pt` |
| `build_general_vector.py` | pools labelled boundary rows across domains (S_general, phase 1 / `--balance` phase 2); also the `cosine` / `load_domain` helpers the combo/control builders import |
| `package_vector.py` | packages a built `…steervec.pt` as `<result>/<name>.pt` + `<name>.meta.json` (keyword lists from `KEYWORD_SETS`, pool/boundary counts from `hidden_*_0_N/hidden.pt`, generation stats from `math_eval.jsonl`, dim / norm); used by the nonreason pipeline, usable for any domain |
| `vector_geometry.py` | CPU report on the finished vectors (norms, cosines, span, weight sensitivity); `DEFAULT_VECTORS` points at the three packaged 1.5B domain vectors (add `--vector nonreason=extraction/nonreason_extraction/nonreason_extraction_1.5B/result/triviaqa_v_nonreason.pt` for the fourth) |
| `gen_logiqa_vllm.py` | LogiQA trace generation + grading (imports the grader from `eval/logic_eval/pipeline/logic_utils.py`) |
| `gen_mbpp_vllm.py` | MBPP trace generation + test execution (legacy v_code MBPP vector) |
| `apps/` | APPS trace generation (`gen_apps_vllm.py`), parquet loader (`data.py`), sandboxed scorer (`scoring.py`) |

MATH traces are generated by the math eval harness itself (`eval/math_eval/pipeline/eval_math_vllm.py --dataset MATH_train`),
so the MATH pool is graded by exactly the same Omni-MATH rule grader as MATH500. TriviaQA (`nonreason`) traces likewise come from
its harness (`eval/nonreason_eval/pipeline/eval_nonreason_vllm.py --dataset TriviaQA_train --em_mode contains`, grader in
`eval/nonreason_eval/pipeline/triviaqa_utils.py`).

Import note: the files here import each other as siblings (`from keyword_sets import KEYWORD_SETS`, `from build_general_vector import cosine`,
`package_vector.py` → `from hidden_analysis import KEYWORD_SETS`).
Scripts elsewhere put this directory on `sys.path` (see the header of `…/pipeline/build_combo_vector.py`).
